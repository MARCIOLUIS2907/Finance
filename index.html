⭐ Método 1 — Safari: adicionar ao Dock (recomendado)

  1. Abra este app no Safari (macOS Sonoma ou mais novo).
  2. No menu: Arquivo → Adicionar ao Dock…
  3. Confirme o nome e clique Adicionar.
  4. Pronto: o ícone abre o app em janela própria, como app nativo.

🌐 Método 2 — Chrome / Edge: instalar como app

  1. Abra este app no Chrome ou Edge.
  2. Clique em ⋮ → Salvar e compartilhar → Instalar página como app… (ou Adicionar à Dock… no Chrome Mac).
  3. Marque Abrir como janela e confirme.

🖱️ Método 3 — Arquivo .webloc no Desktop / Dock

  1. Clique em ⤓ .webloc acima (baixa um arquivo da Apple).
  2. Mova o arquivo para o Desktop.
  3. Arraste para o lado direito da Dock (perto da Lixeira) para fixar.
  4. Duplo-clique abre o app no navegador padrão.

⚙️ Método 4 — Automator (ícone personalizado)

  1. Abra Automator → Novo → Aplicativo.
  2. Adicione Obter URL especificada + cole o link acima.
  3. Adicione Exibir páginas web, salve em Aplicativos.
  4. Arraste o app criado para a Dock.

💡 Dica: depois de adicionar ao Dock pelo Safari/Chrome, clique com botão direito no ícone → Opções → Manter no Dock. Para abrir junto com o Mac: Ajustes → Geral → Itens de início.
