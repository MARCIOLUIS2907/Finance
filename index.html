Ajuda

Guias rápidos das rotinas do app

⬆️ Publicar no GitHub — onde consigo o token
  1. Acesse github.com/settings/tokens (ou clique na sua foto → Settings → role até Developer settings → Personal access tokens → Tokens (classic)).
  2. Clique em Generate new token (classic), dê um nome (ex.: financas-app) e escolha um prazo de validade.
  3. Marque o escopo repo — é ele que libera leitura e escrita de arquivos (o app usa a API de contents para criar/atualizar o arquivo no repo).
  4. Clique em Generate token e copie na hora — ele só aparece uma vez.
  5. Volte ao app (Backup → card GitHub), preencha repo, branch e arquivo, cole o token e clique em Publicar no GitHub. Marque lembrar token só em aparelho seu.

⚠️ O token é como uma senha: quem tiver ele escreve no seu repositório. Se vazar, apague em Settings → Developer settings → Personal access tokens e gere outro.

🔄 Conciliação mensal (app × banco)
  1. Em Sincronização, arraste o OFX do mês: o banner mostra novos, conferidos, duplicados e baixas automáticas.
  2. Em Cadastros → Auditoria, unifique os pares OFX↔manual (um a um) e classifique os sem-par — nunca em lote sem conferir.
  3. Compare o saldo da conta com o saldo do banco (o OFX traz em BALAMT). Diferença persistente pequena (< R$ 1) pode ir num Ajuste de conciliação; o resto se resolve item a item.
💳 Fatura de cartão (Porto / BTG)
  1. Em Sincronização, arraste a fatura: Porto (FaturaAAAAMMDD_MASTER/VISA.xlsx) ou BTG (..._BTG.xlsx, detectado pelo conteúdo — use o Excel, o PDF é só imagem).
  2. Confira o preview e clique em Importar; a fatura entra com cartão, fatura e vencimento.
  3. Ao pagar o boleto, lance o pagamento como saída da conta banco com a etiqueta da fatura (ex.: BTG - Fatura 24/10/2026) — o Relatório (Bloco 7) mostra compras × pagamentos.

⚡ Automático (montagem única): 1) na Sincronização, clique em 🎲 Novo canal e anote o nome; 2) no dashboard, adicione o import do upload-plugin ao main.pjs dele (a linha exata está no topo do código abaixo), cole o bloco abaixo em qualquer <script> do index.html dele (trocando COLE-AQUI-O-CANAL pelo nome, e FIN_PASS pela mesma senha digitada aqui — ou "" nos dois lados p/ sem senha) e chame finAgendar() no fim do persist() dele; 3) salve o dashboard e volte aqui p/ 🔄 Buscar agora (ou marque buscar ao abrir). O dashboard precisa estar salvo (arquivo-ponte exige gerador salvo) e publica sozinho ~1× por minuto quando você edita algo. Sem senha, o conteúdo fica atrás de um nome impossível de adivinhar, mas tecnicamente público — com senha, vai criptografado (AES-256).

📋 Código p/ colar no dashboard (clique p/ abrir) 
// ── main.pjs do dashboard: adicione esta linha ──
uploadPlugin = {import:upload-plugin}

// ── index.html do dashboard: cole dentro de um <script> ──
const FIN_CHAN = "COLE-AQUI-O-CANAL";
const FIN_GEN = "marcioluis-cripto";
const FIN_PASS = "";
let finLastPub = 0, finTimer = null;
function finB64e(bytes){ let s = ""; bytes.forEach(function(c){ s += String.fromCharCode(c); }); return btoa(s); }
async function finPublicar(){
  try {
    const R = window.root || {};
    if (!R.uploadPlugin || !R.uploadPlugin.editable) { console.warn("[ponte-financas] falta o import no main.pjs"); return; }
    const payload = JSON.stringify({ v: 1, atualizadoEm: new Date().toISOString(), gen: FIN_GEN, backup: { operacoes: operacoes, saldosIniciais: saldosIniciais, metodo: metodo } });
    let texto = payload;
    if (FIN_PASS) {
      const te = new TextEncoder();
      const base = await crypto.subtle.importKey("raw", te.encode(FIN_PASS), "PBKDF2", false, ["deriveKey"]);
      const key = await crypto.subtle.deriveKey({ name: "PBKDF2", salt: te.encode("fin-cripto:" + FIN_CHAN), iterations: 60000, hash: "SHA-256" }, base, { name: "AES-GCM", length: 256 }, false, ["encrypt"]);
      const iv = crypto.getRandomValues(new Uint8Array(12));
      const ct = new Uint8Array(await crypto.subtle.encrypt({ name: "AES-GCM", iv: iv }, key, te.encode(payload)));
      texto = JSON.stringify({ v: 1, enc: "aes-gcm", iv: finB64e(iv), data: finB64e(ct) });
    }
    let ek = null; try { ek = localStorage.getItem("fin-ponte-editkey"); } catch (e) {}
    const r = await R.uploadPlugin.editable.set(FIN_CHAN, texto, ek ? { editKey: ek } : undefined);
    if (r && r.error) { console.warn("[ponte-financas]", r.error); return; }
    if (r && r.editKey) { try { localStorage.setItem("fin-ponte-editkey", r.editKey); } catch (e) {} }
    finLastPub = Date.now();
  } catch (e) { console.warn("[ponte-financas]", e); }
}
function finAgendar(){
  const agora = Date.now();
  if (agora - finLastPub > 60000) { finPublicar(); }
  else if (!finTimer) { finTimer = setTimeout(function(){ finTimer = null; finPublicar(); }, 65000 - (agora - finLastPub)); }
}
// No fim do persist() do dashboard, acrescente: try { finAgendar(); } catch (e) {}

⭐ Método 1 — Safari: adicionar ao Dock (recomendado)

  1. Abra este app no Safari (macOS Sonoma ou mais novo).
  2. No menu: Arquivo → Adicionar ao Dock…
  3. Confirme o nome e clique Adicionar.
  4. Pronto: o ícone abre o app em janela própria, como app nativo.

🌐 Método 2 — Chrome / Edge: instalar como app

  1. Abra este app no Chrome ou Edge.
  2. Clique em ⋮ → Salvar e compartilhar → Instalar página como app… (ou Adicionar à Dock… no Chrome Mac).
  3. Marque Abrir como janela e confirme.

🖱️ Método 3 — Arquivo .webloc no Desktop / Dock

  1. Clique em ⤓ .webloc acima (baixa um arquivo da Apple).
  2. Mova o arquivo para o Desktop.
  3. Arraste para o lado direito da Dock (perto da Lixeira) para fixar.
  4. Duplo-clique abre o app no navegador padrão.

⚙️ Método 4 — Automator (ícone personalizado)

  1. Abra Automator → Novo → Aplicativo.
  2. Adicione Obter URL especificada + cole o link acima.
  3. Adicione Exibir páginas web, salve em Aplicativos.
  4. Arraste o app criado para a Dock.

💡 Dica: depois de adicionar ao Dock pelo Safari/Chrome, clique com botão direito no ícone → Opções → Manter no Dock. Para abrir junto com o Mac: Ajustes → Geral → Itens de início.
